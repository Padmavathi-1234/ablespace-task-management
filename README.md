# AbleSpace Task Management System

A modern, full-stack task management application designed to organize, track, and manage tasks efficiently with real-time updates and seamless team collaboration. Built with a scalable monorepo architecture featuring Next.js and NestJS.

## Tech Stack

- **Frontend:** Next.js 14, TypeScript, Tailwind CSS
- **Backend:** NestJS, TypeScript, Prisma
- **Database:** PostgreSQL
- **Deployment:** Vercel (frontend), Railway (backend)

## Project Structure

```
ablespace-task-management/
├── frontend/    # Next.js application
├── backend/     # NestJS application
└── README.md
```
